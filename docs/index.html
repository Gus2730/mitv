Cómo instalarla

Elige tu dispositivo.

  1. Toca Descargar para Android.
  2. Abre el archivo descargado. Si el teléfono lo pide, permite Instalar apps desconocidas para tu navegador o explorador de archivos.
  3. Toca Instalar y abre MiTV.
  4. Las siguientes versiones se instalan encima: la app te avisa cuando hay una nueva.
  1. En la tienda de tu televisor instala la app gratuita Downloader.
  2. Ábrela y escribe esta dirección: MiTV.apk
  3. Cuando termine la descarga, toca Instalar. Si lo pide, activa Instalar apps desconocidas para Downloader en los ajustes del televisor.
  4. MiTV aparece en la pantalla de inicio. Usa las flechas y OK del control; con los números cambias de canal.
  1. Abre MiTV en el navegador con Chrome o Edge.
  2. Para instalarla como app, toca el ícono de instalar en la barra de direcciones (o el botón Instalar en este dispositivo de arriba).
  3. Para ver más canales y usar las grabaciones, descarga el archivo MiTV.html y ábrelo con doble clic: algunos canales gratuitos usan conexiones que los navegadores bloquean dentro de páginas web.
  1. Abre MiTV en Safari.
  2. Toca el botón Compartir y luego Agregar a pantalla de inicio.
  3. Algunos canales y funciones (como la búsqueda por voz) pueden no estar disponibles en iPhone.
Contenido legal. MiTV muestra canales que se transmiten de forma gratuita y abierta por internet (catálogo público iptv-org), radios públicas y el contenido que tú agregues. No incluye canales de pago. Para ver señales como ESPN o Fox Sports, agrega la lista de un proveedor con licencia que tengas contratado.
